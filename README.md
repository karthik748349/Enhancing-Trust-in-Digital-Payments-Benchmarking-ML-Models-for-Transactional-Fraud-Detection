#  Enhancing Trust in Digital Payments: Benchmarking Machine Learning Models for Transactional Fraud Detection

## 📖 Overview

This project presents an intelligent Bank Fraud Detection System that enhances security in digital banking by identifying fraudulent transactions in real time using Machine Learning techniques.

The system continuously monitors banking transactions and analyzes user behavior, transaction patterns, device information, IP addresses, locations, and transaction history to detect suspicious activities and prevent financial fraud.

## 🎯 Objectives

* Detect fraudulent banking transactions in real time.
* Improve trust and security in digital payment systems.
* Reduce financial losses caused by unauthorized transactions.
* Generate instant alerts for suspicious activities.
* Automatically block or lock accounts involved in fraudulent transactions.

## 🧠 Machine Learning Models Used

* K-Nearest Neighbors (KNN)
* Logistic Regression
* Convolutional Neural Network (CNN)
* Statistical Processing Model (SPM) for preprocessing
